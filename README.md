# Website Building WebApp

## Use Cases
We aim to have this webapp used for nonforprofit organizations to be able to create their own websites without having to pay
for external services

## Goals

Our most important goal is to provide an easy way for nonforprofit organizations to be able the build their website how they want it
and allow them to customize it when and where they need to.

## Roadmap

- [x] Add drag and drop functionality
- [x] Allow downloading of page when complete
- [ ] Add User page to allow account creation and design saving
- [ ] Save file to backend server to allow revisiting and re-editing of page
- [ ] (Stretch Goal) We would like to find a way to assist with domain registrations

## Resources
This application uses [Puck](https://puckeditor.com/) and [TipTap](https://tiptap.dev/) to allow users to build drag and drop websites
